# TrustPay AI — Crystal Redesign Kit

Αυτό το kit δίνει στο Codex τις οδηγίες για ολοκληρωμένο redesign του EXISTING TrustPay frontend σε iPhone-inspired Crystal / Liquid Glass UI.

1. Κάνε extract το kit μέσα στο root του πραγματικού TrustPay repository (εκεί όπου υπάρχει το frontend/backend).
2. Άνοιξε τον φάκελο στο VS Code / Codex.
3. Δώσε στο Codex: `Read CODEX_CRYSTAL_REDESIGN_PROMPT.md and implement it completely in the existing project. You may make routine implementation decisions autonomously. Do not stop at planning.`
4. Το `references/glassy-dashboard.tsx` είναι ο αρχικός 21.dev React component. Το `references/demo.tsx` είναι το αρχικό demo. Δεν είναι το τελικό TrustPay UI.

Δεν περιλαμβάνεται ο υπάρχων κώδικας του project, άρα το kit από μόνο του δεν είναι έτοιμο redesigned website. Το Codex πρέπει να τρέξει στο πραγματικό worktree.
